### Objective
Implement an Ant Colony Optimization (ACO) simulation that:
- Creates a graph with 30 nodes connected like a road map
- Assigns random edge costs (1-10)
- Uses ~500 ants to find optimal path between start and finish nodes
- Demonstrates emergent swarm intelligence behavior

### Algorithm Reference
Based on standard Ant System (AS) algorithm:
- **Probability formula**: P(edge) = (pheromone^alpha) * (1/distance)^beta / sum
- **Pheromone update**: pheromone[u,v] += Q / path_length
- **Evaporation**: pheromone[u,v] *= (1 - rho)
- **Parameters**: alpha=2, beta=2, rho=0.1, Q=1

### Algorithm Parameters
- alpha: Pheromone influence exponent (default: 2)
- beta: Distance heuristic exponent (default: 2)
- rho: Evaporation rate (default: 0.1)
- Q: Pheromone deposit constant (default: 1.0)
- n_ants: Ants per iteration (default: 500)
