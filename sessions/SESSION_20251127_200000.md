## Objective
Implement 4th simulation: Agent-based SIR Epidemic Model

## Model Design

### City Layout
- Grid of locations: homes + non-homes (shops, workplaces, etc.)
- Each home has 3 agents
- Agents visit up to 3 nearby non-home locations per day

### Agent States (SIR)
| State | Color | Description |
|-------|-------|-------------|
| Susceptible | Blue | Can be infected |
| Infectious | Red | Can spread disease, lasts N days |
| Recovered | Gray | Immune (permanent or temporary) |

### Parameters
| Parameter | Default | Description |
|-----------|---------|-------------|
| `city_size` | 20 | Grid size (20x20 = 400 locations) |
| `home_density` | 0.5 | Fraction of locations that are homes |
| `agents_per_home` | 3 | Blobs per home |
| `infection_prob` | 0.01 | Chance of infection per interaction |
| `infectious_days` | 2 | How long agents stay infectious |
| `visits_per_day` | 3 | Locations visited per day |
| `initial_infected` | 10 | Starting infected agents |

### Key Metrics
- **R₀**: Basic reproduction number (calculated from simulation)
- **R**: Effective reproduction number (R₀ × fraction susceptible)
- **Herd immunity**: 1 - 1/R₀
