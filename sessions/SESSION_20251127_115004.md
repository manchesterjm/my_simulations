## Key Implementation Details

### Ising GPU - Checkerboard Algorithm
- Divides grid into "black" and "white" squares (like a chessboard)
- All black squares have only white neighbors (and vice versa)
- Can update all black squares in parallel, then all white squares
- Pre-computed acceptance probability lookup table for efficiency

### Sandpile GPU - Batch Mode
- Single drop mode has high kernel launch overhead
- Batch mode drops thousands of grains at once using `cp.bincount()`
- Avalanche processing uses parallel array operations
- Significant speedup at larger grids

### Forest Fire GPU - Hybrid Approach
- GPU: Tree growth, clearing burned cells, random number generation
- CPU: BFS fire spread (graph traversal is inherently sequential)
- GPU-CPU data transfer overhead limits speedup
- Best for large grids (500x500+)
